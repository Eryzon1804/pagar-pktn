Panduan SOP

Petunjuk Teknis Lengkap PAGAR PKTN

Panduan operasional seluruh proses, menu, fitur, dan tata cara pengawasan lapangan.

1. Otentikasi, Akun & Sesi Petugas

Pengguna wajib masuk menggunakan akun Gmail resmi. Akun baru berstatus Pending sampai disetujui Admin pusat. Centang opsi Ingat Saya agar sesi login tetap tersimpan di perangkat. Nama petugas pengawas pertama otomatis terisi sesuai nama akun yang aktif.

2. Pengisian Form & Dropdown Ketersediaan SNI

  • Instansi Otomatis: Instansi langsung terisi *Dinas Perindustrian dan Perdagangan Pemerintah Provinsi NTT*.
  • Dropdown Tersedia / Tidak Ada: Pada bagian NPB dan No. SNI, pilih Tersedia untuk memasukkan nomornya, atau pilih Tidak Ada jika barang tidak mencantumkan nomor.
  • Negara Asal Lainnya: Jika memilih *Lainnya (Impor)*, masukkan nama negara pada kolom tambahan yang muncul.
  • Automasi Temuan: Jika Anda memilih Tidak Ada pada nomor SNI produk/kemasan, sistem otomatis mengubah hasil validasi menjadi **"Tidak Terdaftar (Temuan)"**.
  • Fitur Edit & Hapus Laporan: Laporan dapat diubah atau dihapus satu per satu maupun secara keseluruhan (untuk uji coba).

3. Mode Offline, IndexedDB & Sinkron Cloud

Saat di area tanpa sinyal, data dan foto kualitas penuh tersimpan aman di database lokal (*IndexedDB*) HP. Saat kembali online, petugas dapat melakukan sinkronisasi langsung ke Google Sheets, Google Drive, dan Google Docs pusat melalui tombol sinkron.

4. Navigasi Cepat, FAB & Mode Gelap

  • Tombol Mengambang (FAB): Ketuk tombol bulat plus (`+`) di pojok kanan bawah untuk membuka form baru secara instan.
  • Menu Laci (Drawer Menu): Ketuk ikon garis tiga di pojok kanan atas untuk menu pendukung (Statistik, Sinkron, SOP, Regulasi, Pengaturan).
  • Mode Gelap (Dark Mode): Gunakan tombol ikon bulan/matahari di header atas.

5. Indikator Warna Status Laporan

  • Garis Hijau (Legal): Produk terdaftar dan sesuai SNI.
  • Garis Merah (Temuan): Produk merupakan temuan pelanggaran.
  • Garis Kuning (Pending): Produk belum diverifikasi.
