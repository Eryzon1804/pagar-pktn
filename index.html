Panduan SOP

Petunjuk Teknis Pengawasan PAGAR PKTN

Standar operasional prosedur pengawasan barang beredar & SNI di lapangan.

1. Pendaftaran Akun, Login & Fitur "Ingat Saya"

Pengguna baru wajib mendaftar menggunakan alamat Gmail dan membuat password sendiri. Akun akan berstatus Pending hingga disetujui oleh Admin pusat melalui Panel Admin. Aktifkan centang Ingat Saya saat login agar sesi tetap tersimpan dan Anda tidak perlu mengetik ulang kredensial di kunjungan berikutnya.

2. Tata Cara Pengisian Formulir Secara Rinci

  • Tim Pengawas: Masukkan instansi/unit kerja dan nama petugas. Gunakan tombol Tambah Petugas jika pengawasan dilakukan secara tim.
  • Identitas Toko & GPS: Masukkan nama toko dan pemilik. Nomor Telepon/WhatsApp divalidasi ketat menggunakan format HP Indonesia (misal: 08123456789). Jika salah format, laporan tertolak otomatis. Ketuk Ambil GPS untuk merekam koordinat akurat.
  • Informasi Produk & Validasi SNI: Rinci komoditas, merek, NPB, dan nomor SNI. Jika status dipilih "Terdaftar dan Sesuai (Legal)", kolom NPB dan No. SNI Produk berubah menjadi Wajib Diisi.
  • Dokumentasi Foto: Unggah 5 kategori foto wajib langsung dari kamera HP Anda (Spesifikasi, No. SNI Barang, No. SNI Kemasan, Petunjuk Penggunaan, dan Kartu Garansi).

3. Mode Offline & Fitur Reminder Notifikasi HP

Saat berada di area tanpa sinyal (*offline*), data tetap dapat diisi dan tersimpan secara lokal di memori HP dengan status Belum Terverifikasi. Fitur **Reminder Notifikasi HP** akan aktif otomatis dan mengirimkan pemberitahuan ke layar perangkat Anda begitu koneksi internet pulih, mengingatkan Anda untuk segera melakukan validasi SNI ke Bang Beni v2 dan menyinkronkan data ke server pusat.

4. Fitur Unik di Setiap Menu (Riwayat, Statistik, & Sinkron)

  • Menu Riwayat: Memantau status pengiriman laporan, mengekspor seluruh data ke file CSV, mengetuk laporan untuk membuka menu Detail & Cek guna memperbarui status validasi saat online, serta mengunduh rekap laporan lengkap dalam format **Microsoft Word (.docx)**.
  • Menu Statistik: Menyajikan grafik visual dan diagram persentase tingkat kepatuhan SNI (Legal vs Temuan vs Tidak Sesuai).
  • Menu Sinkron: Memungkinkan sinkronisasi antrean manual saat kembali online dan mengunduh cadangan data lokal dalam format JSON.
